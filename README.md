# CreditLens — NBCFDC Credit Assessment Frontend

A modern React-based frontend for an AI/ML-oriented credit assessment platform designed for NBCFDC beneficiaries.

The application is designed to collect a broader financial profile for beneficiaries who may have limited or no formal credit history. Instead of relying only on traditional credit information, the interface captures financial capacity, repayment behaviour, utility payment patterns, livelihood details and loan requirements.

> **Current status:** Frontend completed. Python ML backend integration is planned.

---

## Features

### Beneficiary Assessment Form

A guided multi-step application collects:

- Personal and household information
- Monthly income and expenses
- Income stability
- Savings behaviour
- Existing loans and outstanding debt
- Previous repayment behaviour
- Missed and overdue payments
- Electricity and water payment behaviour
- Mobile recharge behaviour
- Utility payment methods
- Livelihood and business information
- Loan purpose
- Requested loan amount
- Expected income after the loan
- Expected repayment source

### Interactive Multi-Step Flow

- 7-step assessment journey
- Progress indicator
- Step navigation
- Back and Continue controls
- Form state maintained between steps
- Review before assessment

### Review Dashboard

Before submission, beneficiaries can review:

- Personal information
- Financial profile
- Loan history
- Repayment behaviour
- Alternative payment behaviour
- Livelihood information
- Loan requirements
- Key financial metrics

### Assessment Dashboard

A frontend prototype of the eventual ML output displaying:

- Alternative credit score
- Risk category
- Default probability
- Positive financial factors
- Risk factors requiring attention
- Model assessment information

> The current assessment values are mock data and are not generated by a real ML model yet.
